# Web local documentation index

This archive digest records that `apps/web` used to keep a small local
documentation index alongside the package.

That local index mainly routed readers to four topics:

- package overview and package-local usage notes
- plugin architecture
- frontend-to-backend alignment planning
- graph canvas UX planning and sprint execution notes

## Why this note is archived

- The repository now uses `docs/` as the governed documentation root.
- `apps/web/README.md` remains the package-local entry point for contributors
  working inside the workspace.
- Active architectural and planning routes now live under
  `docs/architecture/components/web/**` and governed planning surfaces.

## Current reader route

- Use [apps/web README](../../../../apps/web/README.md) for workspace-local
  package orientation.
- Use [web component](../../../architecture/components/web/index.md) for the
  active frontend documentation entry point.
