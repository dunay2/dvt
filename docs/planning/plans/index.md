# Planning Plans

Structured implementation plans and remediation subplans derived from active
reviews. These documents are planning inputs, not implementation closeouts.

## Index

- [Domain Cohesion Refactor Plan](domain-cohesion-refactor-plan.md)
- [Domain Cohesion Refactor Subplans](domain-cohesion-refactor-subplans.md)

## Usage

- Use these plans to break large review findings into executable slices.
- Do not mark a slice as closed here unless the corresponding code is shipped
  and validated.
- Create closeout files only after the implementation PR lands or is otherwise
  proven complete.
