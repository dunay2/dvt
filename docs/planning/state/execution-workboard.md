# Execution Workboard

Single execution board for active planning work.

Use this page as the operational tracker that connects:

- task
- objective
- source document
- roadmap lane affected
- dependencies and blockers

This page complements, but does not replace:

- [Roadmap Of Record](../roadmap/index.md)
- [Gap Execution Plans](../gaps/GAP_EXECUTION_PLANS.md)
- [System Delivery Status](../../architecture/system-delivery-status.md)
- [Open Task Route](open-task-route.md)

## Naming Clarification

- Canonical gaps are only `G1` through `G10` in
  [Gap Execution Plans](../gaps/GAP_EXECUTION_PLANS.md), and they are currently
  `Closed`.
- Work item IDs like `G4-PR3`, `G4-PR4`, `G5-PR2`, and `G5-PR4` are proposal PR
  slices and post-gap follow-up tracks.
- Queued/review status in this board for those PR slices does not reopen the
  canonical `G1..G10` gaps unless the gap status changes in the canonical gap
  document.

## Status Legend

- `Queued`: agreed but not started.
- `In Progress`: active implementation.
- `Review`: in PR/review or merge validation.
- `Blocked`: cannot proceed until dependencies close.
- `Done`: closed with evidence.
