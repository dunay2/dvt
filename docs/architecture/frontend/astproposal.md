# DSL Authoring Studio Sketch

This note preserves one early frontend idea for a future DSL-first authoring
surface.

The core idea was:

- a readable declarative DSL editor on the left;
- a live graph preview on the right;
- a bottom panel for problems, compiled plan, generated SQL, and logs.

That idea is still directionally useful, but this file is historical and is not
the canonical source for the active DVT frontend architecture.
