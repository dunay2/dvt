Dbt artifact generation, authoring metadata and Code file scope share one
import-free plugin identifier policy. Characterization preserves the normalized
value and exact caller fallback, including undefined input. The old normalizers
and their current catalog references are removed. DVT/native normalization has
the same current output under a different authoring authority; it does not become
dependent on the dbt plugin. Template normalization has different behavior. This
extraction does not merge those contracts or make Code depend on the Canvas renderer.

Compact Inspector typography uses the existing body scale through shared tokens.
Rendered acceptance checks form controls and read-only facts against the General
tab at two widths, keyboard focus and overflow. Global UI primitives and control
heights are preserved to keep this density change scoped to presentation.

Canonical Code output must receive bounded remaining height through its existing
flex parents. The saved-JOIN browser acceptance measures the actual Monaco
surface at two widths and after a tab roundtrip, rather than checking CSS tokens.
The section policy orders Code last without exposing unsupported sections or
changing explicit tab requests. Long document digests wrap within the Inspector;
the canonical document and editor implementation retain their existing owners.

Code inspection binds both pending and ready SQL results to the exact projection
input references and reuses pending work. Changed graph references, including
layout-only identity changes, conservatively return the display to canonical
output without starting a new query. Tests cover each input, stale completion,
failure/retry and unmount. One shared viewer path retains the existing read-only
contract. Explicit current component entrypoints, atomic source bindings and
required-test records prevent generic folder ownership or absent evidence from
being mistaken for complete architecture coverage.

PostgreSQL's observed backend termination remains unexplained; it is not declared
fixed by this product slice. Existing global component evidence warnings also
remain open. Git preserves prior documentation; no historical copies or parallel
task registry are added.
