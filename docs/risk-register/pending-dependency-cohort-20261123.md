# Test runner and runtime adapter dependency drift

Mixed public and internal Vitest versions can invalidate test execution before
an assertion runs. Removed worker options can silently lose isolation or heap
limits. New coverage defaults can omit unexecuted source and make a passing
percentage misleading. Temporal dependency drift can affect native worker
initialization and workflow replay even when a TypeScript build succeeds.
Mixed Radix interaction modules can also create independent layer and focus
registries, allowing an exiting Tooltip to consume Escape before an active Dialog.

Resolve the Vitest family to one version, use the supported configuration and
retain explicit coverage source inclusion. Prove the worker limits through the
existing catalog contract and prove both a failing low-coverage example and a
passing control with the installed runner. Preserve all coverage thresholds,
test selection, authorization, native proof and required-result fan-in rules.
Resolve the existing Radix DismissableLayer and FocusScope consumers to one
compatible patch version each. Retain the real animated-tooltip/Dialog Escape
regression and its focus restoration assertion.

Run the affected package checks and `pnpm verify:prepush`, including the real
Temporal adapter and browser obligations selected by the complete candidate.
Merge requires successful required hosted checks at the current head and fresh
Planning DB implementation evidence for the exact base/head. A skipped required
aggregate, bot mergeability or old receipt does not establish acceptance.

The [evidence](../evidence/ED-20261123-pending-dependency-cohort.md) records the
observed regressions and focused results. If a compatibility failure remains,
fix it or retain the dependency PR as unintegrated with its exact failure;
never lower a threshold or bypass a hook to admit the update.

Complexity reduction can accidentally duplicate admission, detach session
lifetime from its owner, lose partial artifact-write evidence, or weaken browser
proof. Keep the existing command/query rails and state cells; project passive
contributions without adding sessions, subscriptions or side-effect handlers.
Retain negative scope, revision, cancellation and exactly-once assertions.
Compare CodeScene findings against the same integration base after hook
formatting. An improved score alone does not establish behavioral acceptance.
The recorded review removes all introduced or degraded findings while retaining
the inherited findings and the engine's two unscored authority scripts explicitly.

A combined Model-tab proof can exceed its existing deadline under concurrent
suite load even when unchanged sequential before/after timings are equivalent.
Separate its admission, active-editor retention, released-capacity and neighbor
invariants into focused real-shell scenarios. Keep maximum capacity where the
invariant depends on it, the original deadline and concurrency, both draft
protection cases and no-write assertions. Prove the change with concurrent
Canvas tests and the complete prepush; no failed or interrupted run is a receipt.
Establish full-capacity starting state through actual sequential commands in a
fresh per-test fixture, following the existing draft-test lifecycle. Bound that
preparation explicitly at five seconds and retain the separate five-second test
callback; declare that distinction rather than presenting it as the old combined
budget. Keep global runner settings, graph depth and every assertion unchanged.

A case-specific response appended after shared first-match setup can leave a
browser proof observing the wrong list. Let each Runs case register one explicit
list response through its existing bootstrap helper. Preserve first-match
transport semantics, production filtering, all scenarios and assertions. Prove
the corrected journey and the remaining browser obligations, then rerun the
complete gate; earlier partial successes do not establish readiness.

An initial whole-plan containment limit can interrupt legitimate retained
evidence before completion. The observed complete scope spans approximately
140 minutes across disjoint diagnostic phases. Keep the existing executor and
all selected checks under a finite 180-minute default step and total lifetime;
retain earlier inherited deadlines, cancellation, cooperative cleanup and forced
retirement. Do not renew a deadline in nested wrappers or use partial results as
a receipt. Individual test and fixture deadlines, retries, worker counts and
coverage thresholds remain independent and unchanged. Validate finite-default
propagation and the existing short-budget cancellation and cleanup regressions.

A closing context-menu FocusScope can restore its opener after another Popover
has acquired focus, dismissing that newer surface. Keep handoff in the existing
shared adapter: call the consumer callback once, preserve cancellation and allow
native restoration when no meaningful newer target owns focus. Do not introduce
a selector-dependent workaround, second focus registry, retry or weaker opening
assertion. Prove modal and non-modal ordering with actual primitives and the
unchanged native JOIN journey. Retain every existing rail identity, authorization
rule, source reference and sibling declaration when extending its catalog.

Controlled tab selection can publish duplicate history entries when mousedown
and focus callbacks observe the same uncommitted URL. Use the Router's existing
synchronous commit option so the second callback observes the selected tab.
Preserve automatic activation and meaningful Back/Forward entries without a
second navigation store. Test both native events in one gesture and permit a
fresh visit after Back. Browser proof must traverse the actual Diagnostics and
Summary entries, rather than mask duplication with a numeric history jump.

Reducing workspace-menu complexity must retain callback lifetime and Canvas
scope. Keep one existing latest-props reference, one memoized contribution and
one identity-safe registration effect. Pure projections may copy metadata and
bind available commands, but must preserve absent/undefined behavior, current
callback dispatch and guarded Code close. Foreign-Canvas Model contributions
must remain excluded, and language, disabled actions and canceled file picker
behavior must remain intact. Give the selection submenu its real availability
policy; avoid wrappers that only forward props or create another subscription.
Require the existing complete behavior suite, meaningful scope/lifecycle
characterization, canonical typed lint, types and the actual CodeScene report.
An interrupted earlier candidate cannot authorize the changed final candidate.
