5. Riesgos de gestión detectados¶

  1. Drift doc ↔ issue ↔ código

  2. Hay funcionalidades implementadas con issues todavía abiertos o desalineados en aceptación.

  3. Paridad adapters como cuello de botella

  4. Riesgo de bloquear validación e2e determinista real.

  5. Dualidad roadmap técnico vs backlog producto

  6. Necesita puente explícito de trazabilidad para priorización y reporting.
