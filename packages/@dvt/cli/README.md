# @dvt/cli

Script-oriented validation and golden-path tooling for DVT.

Current reality:

- the exported TypeScript entrypoint is still a placeholder;
- the useful package behavior lives in `validate-contracts.cjs` and
  `run-golden-paths.cjs`;
- the package is not yet a mature user-facing CLI surface.
